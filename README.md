# Netgen website

Sito statico realizzato con HTML, CSS e JavaScript, pronto per GitHub Pages.

## Pubblicazione con GitHub Pages

1. Carica il contenuto di questa cartella nella root del repository.
2. Apri **Settings → Pages**.
3. Seleziona **Deploy from a branch**.
4. Scegli il branch `main` e la cartella `/ (root)`.
5. Salva.

## Prima della pubblicazione definitiva

- Sostituisci `info@netgen.it` con l'indirizzo reale.
- Inserisci il logo SVG definitivo al posto del simbolo provvisorio.
- Aggiorna testi, dati societari, privacy e cookie policy.
